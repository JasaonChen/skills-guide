Hermes Agent Skills 一对一使用指南

完全掌握 Hermes Agent 的 265 个技能 · 让 AI 协作如虎添翼

一、什么是 Skills？

Skills 是 Hermes Agent 的程序性记忆——经过验证的、可重复使用的解决方案，涵盖从日常任务到专业开发的各个领域。每个技能包含：

  • 名称 — 唯一标识符（如 github-code-review）
  • 描述 — 做什么、何时用
  • 触发条件 — 自动匹配的场景（如任务涉及 git diff）
  • 分类 — 所属领域（共 32 个分类）

目前共有 265 个技能分布在 32 个类别中。

二、核心工作流

2.1 自动匹配（最常用）

当你提出需求时，Hermes Agent 会自动：

用户: "帮我 review 这段代码变化"
  ↓
Agent 检索 → 匹配技能: github-code-review
  ↓
加载技能 → 按照预设步骤执行
  ↓
输出结果

你不需要手动操作——系统会自动判断哪个技能适用。

2.2 手动查看技能

想知道 Hermes Agent 会怎么做？随时可以查看：

你可以这样说：
  → "加载 github 相关技能看看"
  → "显示代码审查技能"
  → "打开测试相关的技能"

2.3 触发特定技能

如果系统没有自动匹配，你可以直接指定：

示例：
  → "用 systematic-debugging 模式处理这个 bug"
  → "按 test-driven-development 流程来"
  → "使用 plan 模式先做个规划"

四、自动匹配规则

系统根据你的任务内容自动选择技能。核心匹配逻辑：

  1. 关键词匹配 — 任务描述中的关键词触发对应技能
  2. 文件类型识别 — .py 触发代码技能，.md 触发文档技能
  3. 命令识别 — git 操作触发 GitHub 技能，npm/test 触发开发技能
  4. 意图分析 — "bug" 触发调试技能，"plan" 触发规划技能

五、常用技巧

5.1 组合使用多个技能

复杂任务可以串联多个技能：

  1. 先用 plan 做规划
  2. 再用 writing-plans 写实施方案
  3. 然后用 test-driven-development 开发
  4. 最后用 github-code-review 审查代码

5.2 技能 + 记忆联动

技能是怎么做（步骤、命令、工作流），记忆是关于谁（偏好、环境、设置）。两者互补。

5.3 快速上手新领域

想学习某个领域的最佳实践？加载对应技能即可：

"加载 data-science 分类的技能"
"显示 security-monitoring 相关技能"

七、常见问题

Q: 技能会过期吗？

A: 发现过时或错误的技能时，会自动更新。你也可以要求"更新这个技能"。

Q: 可以自己创建技能吗？

A: 可以！完成复杂任务后，系统会提示"是否保存为技能"。你也可以直接说"把这个流程存成技能"。

Q: 技能冲突怎么办？

A: 系统按优先级选择最匹配的技能。你可以手动覆盖："不用那个，用这个技能"。

Q: 技能和插件的区别？

A: 技能是本地的、经过验证的工作流；插件可能来自外部。技能更可靠、更定制化。

• skills-guide-pdf.html ← 可打印版（A4 优化、分页）
• usage-guide.html ← 使用指南（新手入门、概念解释）
