📚 如何使用 Skills 技能？

Hermes Agent 的 Skills 是可复用的专业能力模块。每个 skill 封装了特定领域的操作流程、API 调用和最佳实践。

💬 方法一：自然语言

直接告诉 Hermes 你想做什么，系统会自动匹配最合适的技能。例如：
帮我搜索 GitHub 上的热门仓库

📋 方法二：指定加载

明确告诉 Hermes 加载某个技能：
加载 github-repo-management 技能

⌨ 方法三：CLI 命令

在 CLI 模式下直接调用：
skill_view('skill-name')

🔄 方法四：自动匹配

描述需求时，Hermes 会扫描所有技能的描述和触发条件，自动加载最匹配的技能。
